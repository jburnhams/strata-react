# Repository guidelines

All rules for this repository (the stack, layout, how to write components and apps, tests,
visual baselines, the changelog and the completion checklist) are in
[`CLAUDE.md`](./CLAUDE.md). Read it before changing anything.

Completion checklist, in short: `npm run build`, `npm test`, `npm run test:integration` and
`npm run test:visual` pass, and `CHANGELOG.md` has an entry for the change.
